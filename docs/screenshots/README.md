# Screenshots

The images in this folder show the real app and are generated by a Playwright run, not by hand.
Everything on them is **example data**: a fictional team ("Northwind Studio" with Ava, Noah, Mia,
Leo and Zoe) on a throwaway Synapse server. Never take README images from a real account.

| File | Content |
|---|---|
| `chat-<theme>.png` | The team chat in one of the ten themes (`light`, `silver`, `dark`, `daaark`, `butter`, `diddy`, `red`, `green`, `purple`, `amber`). `chat-diddy.png` is the README hero. |
| `themes.png` | Montage of all themes (5×2, built from the `chat-*.png`) |
| `settings-appearance.png`, `settings-profile.png` | Settings in the Diddy theme |

## Regenerate

Prerequisites: a local Synapse on `http://127.0.0.1:8008` (server name `localhost`, open registration
without verification, no rate limits) and an accounts file (default `~/diddy-testserver/accounts.txt`,
override with `DIDDY_TEST_ACCOUNTS`; lines of `user password`, created on the first run).

The seed sends messages with real timestamps through an **application service**. Register one in
Synapse (`app_service_config_files`) with `as_token: shots_as_token_0123456789`, `url: null` and a
non-exclusive user namespace `@.*:localhost`; set `DIDDY_TEST_AS_TOKEN` to use another token.

```sh
cd cinny
cp ../config.json . && npm run build   # repo config.json (hashRouter on); do not commit the copy
RESEED=1 npm run shots                  # RESEED=1 rebuilds the example chats
python3 tests/screenshots/montage.py    # themes.png, shrinks the single images (needs Pillow)
```

- macOS (default): Playwright WebKit, the engine of the macOS app (`npx playwright install webkit`).
- Linux: set `DIDDY_SHOTS_CHROME=/path/to/chrome` to render with an installed Chrome instead.
- `SHOTS_ONLY=diddy,settings` renders only some images; `DIDDY_SHOTS_OUT=<dir>` changes the output folder.

On Linux, Synapse is available with `nix build nixpkgs#matrix-synapse`, or without Nix in a venv:
`python3 -m venv venv && venv/bin/pip install matrix-synapse`, then
`venv/bin/python -m synapse.app.homeserver --server-name localhost --config-path homeserver.yaml --generate-config --report-stats=no`
and add `enable_registration`, `enable_registration_without_verification`, generous `rc_*` limits and
`app_service_config_files` (see above) to `homeserver.yaml`. Keep its data outside `/tmp` if `/tmp` is a
small tmpfs.

Chrome on Linux: use the browser Playwright installs (`npx playwright install chromium-headless-shell`,
the version must match the installed Playwright) and point `DIDDY_SHOTS_CHROME` at its
`chrome-headless-shell`. The config starts it with `--disable-dev-shm-usage`, because a small
`/dev/shm` (as in containers) makes Chrome crash while taking the screenshot. Without an emoji font
the emoji in the images are empty boxes: put `NotoColorEmoji.ttf` (googlefonts/noto-emoji, tag
`v2.047`) into `~/.local/share/fonts` and run `fc-cache -f`.
